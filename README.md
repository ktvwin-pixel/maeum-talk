# 5자토크 마음토크

**KOREA CONTENTS LAB**

다섯 자로 묻고, 다섯 자로 답하는 2D 마음 상담 게임.

- 가명, 성별, 20~70대 나이대, 직업군 10가지로 캐릭터를 만들어요.
- 5장 10문항(오늘 · 웃음과 눈물 · 마음의 짐 · 바람 · 확인)에 다섯 자로 답해요.
- 결과로 마음 날씨, 지금 필요한 것, 5자 처방, 실천 세 가지를 받아요.
- 고유 ID와 상담 기록은 플레이한 브라우저에만 저장돼요.
